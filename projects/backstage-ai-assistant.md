# Backstage AI Assistant — Portfolio Case Study

## Overview

This project explores extending a Backstage Developer Portal with a custom backend plugin to retrieve Software Catalog information.

## Problem

Developers working with an internal developer portal may need a convenient way to retrieve information about registered software components and services.

## What I Built

- Created a custom Backstage backend plugin named `ai-assistant`.
- Registered the plugin with the Backstage backend.
- Added an API endpoint to retrieve Software Catalog entities using Backstage's Catalog Service.
- Tested the endpoint through the Backstage frontend using authenticated API requests.

## Technologies

- Backstage
- TypeScript
- React
- Node.js
- Backstage Software Catalog APIs

## Current Status

The custom backend plugin is implemented, and the catalog endpoint has been tested successfully in the development environment.

## Future Improvements
